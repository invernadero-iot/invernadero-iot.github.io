¿Qué es ThingSpeak y para qué sirve?

ThingSpeak es una plataforma IoT en la nube que permite almacenar, visualizar y analizar datos enviados desde dispositivos como el ESP32-S3.

En tu proyecto, el ESP enviará datos (temperatura, sensores, etc.) a un canal personal usando una clave llamada Write API Key.

🔹 Paso 1: Crear una cuenta

Ingresa al sitio oficial:

https://thingspeak.com

Crea una cuenta gratuita.

🔹 Paso 2: Crear un Channel

Una vez dentro:
  • Haz clic en Channels
  • Selecciona New Channel
  • Asigna un nombre
  • Activa los campos que usarás (Field1, Field2, etc.)
  • Guarda el canal

🔹 Paso 3: Obtener la Write API Key

Dentro de tu canal:
  • Ve a la pestaña API Keys
  • Copia la Write API Key
  • Pégala en la página principal de configuración

📌 ¿Por qué es necesaria?

La API Key funciona como una contraseña que autoriza al ESP32 a enviar datos a tu canal. Sin ella, ThingSpeak rechazará la información.
