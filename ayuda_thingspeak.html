¿Qué es ThingSpeak?

ThingSpeak es una plataforma IoT que permite almacenar y visualizar datos en la nube. El ESP32-S3 enviará información a tu canal usando una API Key.

¿Cómo obtener la Write API Key?

  1. Crear una cuenta en https://thingspeak.com
  2. Crear un nuevo Channel
  3. Ir a la sección "API Keys"
  4. Copiar la "Write API Key"
  5. Pegarla en la página principal
