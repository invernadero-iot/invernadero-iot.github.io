¿Qué es el ID de Google Sheets?

El ID es el identificador único de tu hoja de cálculo en Google. El ESP32 enviará datos a esa hoja usando ese ID.

🔹 Paso 1: Crear una hoja

Ingresa a:

https://drive.google.com

Crea una nueva hoja de cálculo.

🔹 Paso 2: Obtener el ID

Cuando abras la hoja, verás una URL como esta:

https://docs.google.com/spreadsheets/d/1AbCDeFgHiJkLmNoPqRsTuVwXyZ123456789/edit

El ID es la parte que está entre:
/d/ y /edit

🔹 Paso 3: Copiar y pegar

Copia ese ID y pégalo en la página principal de configuración.

📌 ¿Por qué es necesario?

El ID permite que el sistema sepa exactamente en qué documento guardar los datos enviados desde el ESP32.
